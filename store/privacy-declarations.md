# 직관일기 2.4.0 스토어 개인정보 선언

기준일: 2026-09-03

실제 앱 코드, Google Mobile Ads SDK 공개 문서, 기존 기록 복구 설계를 기준으로 작성한 제출용 원본이다. 콘솔 질문이 바뀌면 문구가 아니라 실제 데이터 흐름을 기준으로 다시 확인한다.

## 공통 원칙

- 계정 생성·로그인·클라우드 동기화 없음
- 새 닉네임, 응원 팀, 직관 기록, 메모, 사진·티켓은 기기에만 저장
- 정밀 위치, 연락처, 마이크, 카메라 권한 요청 없음
- 사진은 사용자가 시스템 선택기에서 고른 항목만 앱 전용 공간으로 복사
- 알림은 기기 내 로컬 알림이며 푸시 토큰을 생성하거나 서버로 전송하지 않음
- 광고는 맞춤형이 아닌 광고로 요청하고 iOS ATT 권한은 요청하지 않음
- 기존 기록 복구 기간에 한해 해시된 기기 확인값, 앱·기기 증명, 일회용 복구 상태를 처리
