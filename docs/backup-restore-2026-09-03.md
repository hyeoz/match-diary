# 전체 백업·복원 구현 결과

작성일: 2026-09-03  
대상: 직관일기 재운영 로드맵 7단계(사용자 작업 순서 8단계)

## 구현 범위

- 프로필, 직관 기록, 사진·티켓, 경기 일정, 경기장, 예약 알림을 하나의 `.matchdiary` 파일로 내보낸다.
- 운영체제 공유·파일 저장 화면을 사용하므로 iCloud Drive, Google Drive, 내 파일 등 사용자가 선택한 앱 외부 위치에 보관할 수 있다.
- 새 설치의 첫 화면과 기존 앱의 설정 화면에서 같은 백업 파일을 복원할 수 있다.
- 복원은 기존 데이터를 지우지 않고 병합하며, 같은 기록 ID는 중복 생성하지 않는다.
- 복원된 미래 알림은 새 기기의 로컬 알림으로 다시 예약한다. 권한이 없으면 데이터는 복원하고 예약 실패 개수만 안내한다.

## `.matchdiary` v1 규격

`.matchdiary`는 ZIP 컨테이너이며 다음 파일만 포함한다.

```text
manifest.json
data.json
checksums.json
media/
  photos/*
  tickets/*
```

- `manifest.json`: 포맷 식별자, 규격 버전, 생성 시각, 앱 버전, 기록·미디어·알림 수, 전체 미디어 크기, 체크섬 목록의 SHA-256
- `data.json`: 프로필, 기록, 일정, 경기장, 알림과 미디어 메타데이터
- `checksums.json`: `data.json`과 모든 미디어 파일의 SHA-256
- `media/*`: 앱 전용 저장소에서 복사한 사진·티켓 원본

현재 규격 버전은 `1`이며, 앱이 이해할 수 없는 더 높은 버전은 기존 데이터를 건드리지 않고 거부한다.

## 복원 안전장치

1. 파일 선택 결과를 앱 캐시에 복사한다.
2. 압축을 풀기 전에 암호화 항목, 절대 경로, 상위 경로(`..`), 역슬래시 경로를 거부한다.
3. 압축 해제 예상 크기를 확인하고 8GB를 넘는 파일과 여유 공간이 부족한 기기를 거부한다.
4. 임시 폴더에서 manifest, 데이터 계약, 개수, 참조 관계, 중복 ID, 전체 파일 목록과 SHA-256을 검증한다.
5. 검증된 사진·티켓만 앱 전용 저장소의 새 경로로 복사한다.
6. SQLite 트랜잭션 안에서 일정·경기장·프로필·기록·알림을 병합한다.
7. DB 병합에 실패하면 새로 복사한 파일을 제거한다. 비정상 종료로 파일이 남아도 다음 시작 시 고아 파일 정리가 제거한다.
8. 복원에 사용한 임시 파일은 즉시 삭제한다. 내보낸 파일은 Android 수신 앱이 공유 완료 뒤에도 읽을 수 있도록 캐시에 잠시 유지하고 다음 앱 시작이나 백업 때 정리한다.

손상되거나 조작된 파일, 미디어 누락, 잘못된 참조, 저장 공간 부족이 발생하면 복원 전의 앱 데이터는 유지된다.

## 병합 규칙

- 백업 프로필이 있으면 닉네임과 응원 팀을 복원한다.
- 기록 ID가 이미 있으면 현재 기록을 유지하고 백업의 같은 기록은 건너뛴다.
- 새 기록의 사진과 티켓은 새 앱 전용 경로에 저장한다.
- 백업에 포함된 일정·경기장 데이터는 기록 참조를 온전히 복원하기 위해 함께 병합한다. 이후 정상적인 원격 일정 갱신이 최신 상태를 반영한다.
- 알림의 과거 네이티브 식별자는 사용하지 않는다. 복원 후 미래 알림만 새 기기에서 다시 등록한다.

## 사용자 흐름

### 기존 설치

`설정 → 백업 생성`에서 파일을 안전한 외부 위치에 저장하고, `설정 → 백업 복원`에서 파일을 선택한다. 설정 화면에는 마지막으로 성공한 백업 생성 시각을 표시한다.

### 앱 삭제·재설치 또는 새 기기

최초 시작 화면의 `백업에서 복원`을 누르면 프로필을 만들기 전에도 백업 파일을 선택할 수 있다. 백업에 프로필이 없으면 기록은 복원한 뒤 닉네임과 응원 팀 설정으로 안내한다.

## 보안과 보관 주의

백업 파일에는 개인 메모와 사진이 포함된다. 기본 백업·복원 범위에 맞춰 파일 자체 암호는 적용하지 않았으므로, 사용자가 신뢰하는 기기 저장소나 개인 클라우드에 보관해야 한다. 앱 외부에 저장한 백업은 앱 삭제나 앱 내 모든 데이터 삭제와 함께 지워지지 않는다.

압축 항목 사전 검사와 안전한 경로 검사를 제공하는 현재 네이티브 ZIP 모듈을 사용하기 위해 iOS 최소 지원 버전은 15.5로 정리했다.
