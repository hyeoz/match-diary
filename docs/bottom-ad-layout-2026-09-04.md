# TestFlight 하단 광고 영역 수정

## 원인

광고 SDK 초기화 완료 상태를 배너 표시 상태로 사용하고 있었다. 그 결과 운영 광고가 아직 로드되지 않았거나 로드에 실패해도 네이티브 배너 뷰가 하단 높이를 차지했다.

추가로 메인 화면과 하단 탭이 iPhone 하단 안전영역을 각각 적용하고 있었으며, 가운데 `기록` 탭은 음수 여백으로 탭바 밖에 돌출돼 콘텐츠 영역을 덮었다. 일부 화면에는 탭바와 무관한 110pt대 고정 하단 여백도 남아 있었다.

## 수정

- 배너가 `onAdLoaded`를 전달하기 전에는 컨테이너 높이를 `0`으로 유지한다.
- `onAdFailedToLoad`가 전달되면 배너를 언마운트한다.
- 실제 광고가 표시될 때만 배너 높이와 상단 구분선을 적용한다.
- 광고가 없는 상태에서는 콘텐츠 다음에 하단 탭이 바로 이어진다.
- 메인 탭 화면에서는 상단·좌우 안전영역만 적용하고, 하단 안전영역은 탭바에서 한 번만 처리한다.
- `기록` 탭 강조는 탭바 내부의 작은 초록 버튼으로 바꿔 콘텐츠 위로 돌출되지 않게 한다.
- 메인 화면의 110pt대 고정 하단 여백을 제거하고 16pt의 자연스러운 스크롤 여백만 둔다.

## 검증

- 광고 미표시 상태의 소형·대형 iPhone 및 iPhone 16 Pro 시뮬레이터에서 캘린더 콘텐츠와 하단 탭 사이에 빈 광고 영역이나 탭 돌출이 없음을 확인했다.
- iPhone 16 Pro에서 광고 표시 상태도 확인해 콘텐츠 스크롤 경계, 광고, 탭바가 차례로 배치되는지 검증했다.
- 배너가 실제로 표시되기 전 높이가 `0`인지 회귀 테스트로 고정했다.
